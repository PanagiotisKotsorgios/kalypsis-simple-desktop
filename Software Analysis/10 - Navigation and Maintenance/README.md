# Πλοήγηση και εργαλεία συντήρησης

Το dropdown «Πλοήγηση» δημιουργείται από την ίδια λίστα δέκα ενοτήτων με το sidebar. Δίπλα σε κάθε ενότητα φαίνεται η συντόμευση `Ctrl+1` έως `Ctrl+0`. Η οθόνη συντομεύσεων περιλαμβάνει και τα νέα εργαλεία.

Το dropdown «Εργαλεία» περιλαμβάνει διαχείριση χρηστών, αρχείο ελέγχου, αντίγραφα ασφαλείας και ημερολόγιο σφαλμάτων. Τα δύο τελευταία είναι διαθέσιμα μόνο σε διαχειριστές. Οι «Ρυθμίσεις» διατηρούν τις ρυθμίσεις συστήματος, τη διαχείριση συντομεύσεων και την παραμετροποίηση φίλτρων.

Τα αντίγραφα δημιουργούνται μέσω του SQLite backup API στον τοπικό φάκελο `%LOCALAPPDATA%\KalypsisSimpleSoftware\Data\Backups`. Κάθε νέο αρχείο ελέγχεται με `PRAGMA integrity_check`. Πριν από επαναφορά, δημιουργείται αυτόματα αντίγραφο της τρέχουσας βάσης. Η επαναφορά απαιτεί επιβεβαίωση στην εφαρμογή και επανεκκίνηση μετά την ολοκλήρωσή της. Τα αντίγραφα δεν κρυπτογραφούνται από την εφαρμογή.

Το ημερολόγιο καταγράφει σφάλματα υπηρεσιών και μη χειρισμένα σφάλματα UI σε JSON Lines αρχείο `%LOCALAPPDATA%\KalypsisSimpleSoftware\Logs\errors.jsonl`. Το αρχείο περιστρέφεται όταν ξεπεράσει τα 5 MB. Η οθόνη παρέχει αναζήτηση και τεχνικές λεπτομέρειες για τις 300 πιο πρόσφατες εγγραφές.

Η στήλη «Κινητό» έχει αφαιρεθεί από τον πίνακα πελατών και από τη διαχείριση στηλών. Το κινητό παραμένει πεδίο της καρτέλας πελάτη και διαθέσιμο στην αναζήτηση.
