# Phase 02 — Διεπαφή εργασίας

**Προϊόν:** KALYPSIS SIMPLE SOFTWARE

**Δημιουργός:** KALYPSIS SOFTWARE SOLUTIONS

**Πλατφόρμα:** Windows, WinUI 3

**Γλώσσα διεπαφής:** Ελληνικά

## Σκοπός

Η δεύτερη φάση παρέχει το περιβάλλον μετά τη σύνδεση: πλοήγηση, ξεχωριστή οθόνη για κάθε επιχειρησιακή ενότητα, εργαλεία διαχειριστή, ρυθμίσεις, συντομεύσεις, βοήθεια και γραμμή κατάστασης. Η πιστοποίηση, η ανάκτηση πρόσβασης, η βάση SQLite και οι έλεγχοι δικαιωμάτων της πρώτης φάσης παραμένουν ενεργοί.

Τα επιχειρησιακά δεδομένα (πελάτες, οχήματα, συμβόλαια κ.λπ.) δεν έχουν ακόμη μοντέλο, αποθήκευση ή λειτουργίες δημιουργίας/επεξεργασίας. Οι οθόνες τους παρουσιάζουν αναζήτηση, σχετικά πεδία και σαφή κενή κατάσταση, ώστε να υλοποιηθούν στην επόμενη φάση με συμφωνημένους κανόνες.

## Παράθυρο και ταυτότητα

- Το παράθυρο σύνδεσης προσαρμόζεται στη διαθέσιμη οθόνη και οι μεγάλες φόρμες κυλίονται, ώστε να παραμένουν προσβάσιμα τα κουμπιά.
- Μετά την επιτυχή σύνδεση το παράθυρο μεγιστοποιείται. Το περιεχόμενο προσαρμόζεται όταν αλλάζει το μέγεθος της οθόνης ή του παραθύρου.
- Το λογότυπο που έδωσε ο χρήστης χρησιμοποιείται στις σελίδες πιστοποίησης, στην κεφαλίδα, στο εκτελέσιμο και στη συντόμευση επιφάνειας εργασίας.
- Το προϊόν ονομάζεται **KALYPSIS SIMPLE SOFTWARE** σε όλη τη διεπαφή. Η αποσύνδεση τερματίζει τη συνεδρία και επιστρέφει στη σύνδεση.

## Πλευρική πλοήγηση

Η επαναλαμβανόμενη καταχώριση «Οχήματα» αφαιρέθηκε κατόπιν επιβεβαίωσης. Κάθε ενότητα έχει κείμενο 18 px και μεγαλύτερο εικονίδιο 38 px με μικρό διάκενο 8 px, δικό της τίτλο, περιγραφή, χρώμα, προτροπή αναζήτησης και πεδία προβολής. Τα δέκα εικονίδια είναι τα ακριβή αρχεία PNG που έδωσε ο χρήστης και αντιγράφονται στο `Assets/Sections`.

| Ενότητα | Εικονίδιο χρήστη | Περιεχόμενο οθόνης |
|---|---|---|
| Πελάτες | `patient.png` | Πελάτες, επικοινωνία, κατάσταση |
| Συνεργάτες | `cooperation.png` | Συνεργάτες, περιοχή, κατάσταση |
| Οχήματα | `car.png` | Πινακίδα, όχημα, ιδιοκτήτης, κατάσταση |
| Εταιρείες | `enterprise.png` | Εταιρεία, κλάδος, επικοινωνία |
| Πρακτορεία | `office-building.png` | Πρακτορείο, περιοχή, υπεύθυνος |
| Ασφαλιστήρια | `contract.png` | Αριθμός, πελάτης, εταιρεία, λήξη |
| Ζημιές | `fender-bender.png` | Υπόθεση, πελάτης, ημερομηνία, κατάσταση |
| Ενημέρωση | `mail.png` | Θέμα, κατηγορία, ημερομηνία |
| Αναφορές | `bar-graph.png` | Αναφορά, περίοδος, τελευταία εκτέλεση |
| Γέφυρες Εταιρειών | `connection.png` | Εταιρεία, τύπος σύνδεσης, κατάσταση |

## Κεφαλίδα και εργαλεία

- **Πλοήγηση:** γρήγορες μεταβάσεις σε Πελάτες, Ασφαλιστήρια, Ζημιές και Αναφορές.
- **Εργαλεία:** διαχείριση χρηστών και αρχείο ελέγχου. Οι ενέργειες χρηστών περιλαμβάνουν δημιουργία, ανάθεση/αφαίρεση ρόλου, επαναφορά κωδικού υπαλλήλου και απενεργοποίηση. Η εφαρμογή ελέγχει τα δικαιώματα και προστατεύει τον τελευταίο διαχειριστή.
- **Ρυθμίσεις:** επιλογή φωτεινού, σκούρου ή προεπιλεγμένου θέματος, πληροφορίες τοπικής βάσης και πολιτικής κλειδώματος, καθώς και οθόνη συντομεύσεων με δυνατότητα ενεργοποίησης/απενεργοποίησης.
- **Βοήθεια:** οδηγός, επικοινωνία (`info@mykalypsis.gr`, `2631028971`) και πληροφορίες προϊόντος KALYPSIS SOFTWARE SOLUTIONS.
- **Αποσύνδεση:** σταθερό κόκκινο φόντο και λευκό κείμενο σε κάθε θέμα.

Οι συντομεύσεις είναι `Ctrl+1` έως `Ctrl+0` για τις δέκα ενότητες, `Ctrl+U` για χρήστες, `Ctrl+J` για αρχείο ελέγχου, `Ctrl+K` για συντομεύσεις, `Ctrl+S` για ρυθμίσεις, `F1` για βοήθεια και `Ctrl+Shift+Q` για αποσύνδεση. Οι επιλογές θέματος και ενεργοποίησης συντομεύσεων αποθηκεύονται ανά χρήστη Windows στο `%LOCALAPPDATA%/AllInsurance/ui-settings.json`.
