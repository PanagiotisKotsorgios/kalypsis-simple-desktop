# Φωτεινό θέμα εφαρμογής

Το φωτεινό θέμα χρησιμοποιεί κοινή γκρι παλέτα για φόντο σελίδας, κάρτες, λίστες, πίνακες, φίλτρα, sidebar, επάνω μπάρα και footer. Τα πεδία κειμένου, επιλογής και ημερομηνίας έχουν διακριτό γκριζογάλαζο φόντο και ορατό περίγραμμα. Τα αναδυόμενα μενού και παράθυρα ακολουθούν την ίδια παλέτα.

Η παλέτα ορίζεται κεντρικά στο `App.xaml` για τα φωτεινά και τα προεπιλεγμένα Windows θέματα. Τα ανεξάρτητα παράθυρα καρτελών πελάτη, συνεργάτη, οχήματος, ασφαλιστηρίου και λοιπών εγγραφών χρησιμοποιούν το ίδιο φόντο σελίδας. Τα σημασιολογικά χρώματα ενεργειών, υπολοίπων και καταστάσεων διατηρούνται.
