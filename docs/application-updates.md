# Αναβαθμίσεις εφαρμογής

Η εντολή **Εργαλεία → Αναβάθμιση εφαρμογής** ελέγχει το τελευταίο δημοσιευμένο GitHub Release. Η εφαρμογή συγκρίνει το tag έκδοσης με την εγκατεστημένη έκδοση, κατεβάζει ολόκληρο το Windows πακέτο και επαληθεύει το SHA-256 digest που επιστρέφει το GitHub API. Δεν χρησιμοποιούνται αυθαίρετα εκτελέσιμα από φακέλους του αποθετηρίου.

Η νέα εφαρμογή εγκαθίσταται στο `%LOCALAPPDATA%\AllInsurance\AppVersions\<έκδοση>` και ενημερώνεται η συντόμευση της επιφάνειας εργασίας. Η βάση `%LOCALAPPDATA%\KalypsisSimpleSoftware\Data\allinsurance.db`, τα αντίγραφα ασφαλείας και τα αρχεία εγγραφών δεν μετακινούνται ούτε διαγράφονται. Μετά τη λήψη η εφαρμογή επανεκκινεί και εμφανίζει μήνυμα επιτυχίας στην οθόνη σύνδεσης. Αν αποτύχει ο έλεγχος ή η εκκίνηση, η τρέχουσα εφαρμογή παραμένει ανοιχτή.

Για δημοσίευση νέας έκδοσης, δημιουργήστε και ανεβάστε tag `v<major>.<minor>.<patch>` (για παράδειγμα `v0.7.13`). Το workflow `Desktop release` υπογράφει το πλήρες self-contained πακέτο `kalypsis-simple-desktop-win-x64.zip`, δημιουργεί υπογεγραμμένο εγκαταστάτη Windows και αναρτά και τα δύο σε GitHub Release. Απαιτούνται τα μυστικά υπογραφής που περιγράφονται στον [οδηγό διανομής](windows-distribution.md). Το πρώτο release είναι η βασική εγκατεστημένη έκδοση· η εντολή θα προσφέρει λήψη όταν δημοσιευτεί μεγαλύτερη έκδοση.
