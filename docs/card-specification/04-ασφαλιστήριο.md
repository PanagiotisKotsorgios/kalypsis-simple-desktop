# Καρτέλα ασφάλισης, αιτήσεις και ανανεώσεις

Μία εγγραφή `BusinessRecord` (`SectionKey=policies`) αντιπροσωπεύει **προσφορά, αίτηση, ειδοποιητήριο, ασφαλιστήριο, πρόσθετη πράξη ή πράσινη κάρτα**. Ο τύπος βρίσκεται στο `DocumentType`, τα ειδικά δεδομένα στο `PolicyCardData` JSON. Το ανανεωτήριο είναι νέο ασφαλιστήριο συνδεδεμένο με το προηγούμενο (`PreviousPolicyId`/`PreviousPolicyNumber`), με διακριτό αριθμό ανανεωτηρίου. Η οθόνη «Ανανεώσεις» οδηγεί στην ίδια καρτέλα.

## Tab «Καρτέλα ασφάλισης»

| Πεδίο | Τύπος / επιλογές | Ιδιότητα / κανόνας |
|---|---|---|
| Τύπος εγγράφου * | Προσφορά · Αίτηση · Ειδοποιητήριο · Ασφαλιστήριο · Πρόσθετη πράξη · Πράσινη κάρτα | `DocumentType`; στη νέα εγγραφή αρχικά προσφορά/αίτηση/ειδοποιητήριο |
| Αριθμός προσφοράς | Κείμενο, υποχρεωτικό για προσφορά | `OfferNumber` |
| Αριθμός αίτησης | Κείμενο, υποχρεωτικό για αίτηση | `ApplicationNumber` |
| Αριθμός ειδοποιητηρίου | Κείμενο, υποχρεωτικό για ειδοποιητήριο | `NoticeNumber` |
| Αριθμός ασφαλιστηρίου | Κείμενο, υποχρεωτικό για ασφαλιστήριο | `PolicyNumber` |
| Αριθμός ανανεωτηρίου | Κείμενο | `RenewalNumber` |
| Προηγούμενο ασφαλιστήριο | Κείμενο/σύνδεση | `PreviousPolicyNumber`, `PreviousPolicyId` |
| Ασφαλιστική εταιρεία | Αναζήτηση στις καταχωρισμένες εταιρείες + άνοιγμα καρτέλας | `Insurer`, `CompanyId` |
| Πρακτορείο | Αναζήτηση στα καταχωρισμένα πρακτορεία + άνοιγμα | `Agency`, `AgencyId` |
| Συνεργάτης | Αναζήτηση/επιλογή + άνοιγμα | `PartnerId` |
| Αντικείμενο ασφάλισης / κλάδος | Αναζήτηση σε παραμετρικούς κλάδους | `Branch` |
| Προϊόν / πακέτο | Αναζήτηση, περιορίζεται από εταιρεία/κλάδο | `Product` |
| Πελάτης / ιδιοκτήτης * | Αναζήτηση πελάτη + άνοιγμα καρτέλας | `BusinessRecord.CustomerId` |
| Κάτοχος / συμβαλλόμενος | Επιλογή πελάτη, «Ίδιος με ασφαλισμένο» | `HolderCustomerId` |
| Συνδεδεμένο όχημα | Αναζήτηση **στα οχήματα του επιλεγμένου πελάτη**, άνοιγμα καρτέλας | `VehicleId` |
| Κατάσταση | Δυναμική λίστα ανά τύπο (παρακάτω) | `BusinessRecord.Status` |
| Ημερομηνία έκδοσης | Ημερομηνία | `IssueDate` |
| Έναρξη κάλυψης | Ημερομηνία | `StartDate` |
| Διάρκεια κάλυψης | Προσαρμοσμένη ή προκαθορισμένοι μήνες | `CoverageDurationMonths` |
| Ακριβής διάρκεια | Αριθμός + Ημέρες / Μήνες / Έτη | `CoverageDurationValue`, `CoverageDurationUnit` |
| Λήξη κάλυψης | Ημερομηνία· ενημερώνεται από έναρξη/διάρκεια | `EndDate` |
| Πληρωμή προς ασφαλιστική έως | Ημερομηνία· μπορεί να υπολογιστεί από ημερομηνία έκδοσης + πιστωτικές ημέρες εταιρείας | `CompanyPaymentDueDate` |
| Προθεσμία απόδοσης | Υπολογισμός ημερών ως την πληρωμή εταιρείας | Δεν αποθηκεύεται χωριστά |
| Συνήθης τρόπος πληρωμής | Κενό · Μετρητά · Κάρτα · Τραπεζική μεταφορά · POS · Πάγια εντολή · Ταχυπληρωμή | `PreferredPaymentMethod`; προεπιλογή στην είσπραξη |
| Πού πληρώνει ο πελάτης | Στο γραφείο · Στην ασφαλιστική · Στο πρακτορείο | `PaymentRecipient` |
| Κωδικός ταχυπληρωμής / πληρωμής | Κείμενο | `PaymentCode` |
| Καθαρά ασφάλιστρα | Ποσό | `NetPremium`· βάση υπολογισμού προμηθειών |
| Μικτά ασφάλιστρα | Ποσό | `GrossPremium` |
| Υπόλοιπο ασφαλιστηρίου | Υπολογισμός | Μικτά − εισπράξεις + επιστροφές/πληρωμές |

### Καταστάσεις ανά είδος

| Είδος | Διαθέσιμες καταστάσεις |
|---|---|
| Προσφορά | Πιθανό, Σε αναμονή, Αποδεκτή, Απορρίφθηκε, Ακυρωμένο |
| Αίτηση | Σε εξέλιξη, Προς έκδοση, Εκδόθηκε, Ακυρωμένο |
| Ειδοποιητήριο | Σε αναμονή πληρωμής, Πληρωμένο, Ακυρωμένο |
| Πράσινη κάρτα / Πρόσθετη πράξη | Σε εξέλιξη, Εκδόθηκε, Παραδόθηκε, Ακυρωμένο |
| Ασφαλιστήριο | Ενεργό, Ανανεωμένο, Ληγμένο, Ακυρωμένο, Ανενεργό |

| Υποσύνολο | Πεδία / στήλες | Ενέργειες |

| Αρχεία | Όνομα, τύπος, διαδρομή/σύνδεση | Επισύναψη PDF, PNG, JPG, JPEG ή DOCX· άνοιγμα· διαγραφή |

## Ιστορικό, ζημιές και ενέργειες
