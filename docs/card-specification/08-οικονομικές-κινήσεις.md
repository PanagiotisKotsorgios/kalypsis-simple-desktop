# Καρτέλες οικονομικών κινήσεων

## Είσπραξη και πληρωμή πελάτη

Βάση: `CustomerTransaction`. Δημιουργείται από καρτέλα πελάτη, καρτέλα ασφαλιστηρίου ή μαζική ενέργεια· εμφανίζεται στη λίστα «Εισπράξεις» / «Πληρωμές» και στα οικονομικά του πελάτη.

| Πεδίο | Τύπος / επιλογές | Ιδιότητα / κανόνας |
|---|---|---|
| Αριθμός κίνησης | Αναγνωριστικό, μόνο προβολή | `Id` |
| Είδος | Είσπραξη · Πληρωμή | `Type` (`receipt` / `payment`) |
| Πελάτης * | Συνδεδεμένη καρτέλα | `CustomerId` |
| Ασφαλιστήριο | Αναζήτηση στα ασφαλιστήρια του πελάτη | `BusinessRecordId`· σύνδεση εγγραφής |
| Ποσό * | Θετικό ποσό σε ευρώ | `Amount` |
| Τρόπος πληρωμής * | Μετρητά, κάρτα, τραπεζική μεταφορά, POS, πάγια εντολή, ταχυπληρωμή κ.ά. | `PaymentMethod`· προεπιλογή από ασφαλιστήριο |
| Νόμισμα | EUR εξ ορισμού, μόνο προβολή στη συναλλαγή | `Currency`· αλλαγή κεντρικά από διαχειριστή όπου επιτρέπεται |
| Αριθμός συναλλαγής / αναφορά | Κείμενο | `Reference` |
| Αιτιολογία / σημειώσεις | Πολυγραμμικό | `Description` |
| Ημερομηνία/ώρα | Αυτόματη καταχώριση UTC, τοπική προβολή | `OccurredAtUtc` |
| Χρήστης καταχώρισης | Σύνδεση χρήστη | `CreatedByUserId` |

### Καρτέλα προβολής κίνησης

| Πεδίο/ενέργεια | Περιεχόμενο |
|---|---|
| Αριθμός κίνησης · Είδος · Ημερομηνία · Πρόσωπο/φορέας · Ασφαλιστήριο | Ταυτότητα και συνδέσεις |
| Ποσό · Νόμισμα · Τρόπος πληρωμής · Αναφορά · Πηγή καταχώρισης · Αιτιολογία | Λεπτομέρειες κίνησης |
| Ιστορικό καταχώρισης | Χρόνος και αναφορά |
| Ασφαλιστήριο / Καρτέλα προσώπου / Κλείσιμο | Άνοιγμα συνδεδεμένων καρτελών |

### Πίνακες «Εισπράξεις» και «Πληρωμές»

| Λειτουργία | Περιγραφή |
|---|---|
| Λίστα | Συγκεντρώνει κινήσεις από όλες τις καρτέλες |
| Αναζήτηση και φίλτρα | Πρόσωπο, ασφαλιστήριο, ημερομηνίες, τρόπος πληρωμής και άλλες διαθέσιμες τιμές της οθόνης |
| Διπλό κλικ | Ανοίγει πλήρη καρτέλα προβολής κίνησης |
| Μαζική είσπραξη/πληρωμή | Επιλεγμένοι πελάτες ή συνεργάτες, κοινό ποσό, τρόπος, αναφορά, αιτιολογία |
| Εξαγωγή/εκτύπωση | Ορατές στήλες και επιλεγμένες εγγραφές όπου προσφέρονται από τον πίνακα |

## Κινήσεις συνεργάτη

Βάση: `PartnerPayout`. Η οικονομική καρτέλα εμφανίζει προμήθειες ασφαλιστηρίων, πληρωμές, εισπράξεις και χειροκίνητες προμήθειες σε χρονολογικό καθολικό.

| Πεδίο | Τύπος / τιμές | Ιδιότητα |
|---|---|---|
| Συνεργάτης * | Σύνδεση | `PartnerId` |
| Ασφαλιστήριο | Προαιρετική σύνδεση | `PolicyId` |
| Ποσό (€) * | Θετικός αριθμός | `Amount` |
| Είδος | Πληρωμή · Είσπραξη · Χειροκίνητη προμήθεια | `Kind` (`payment`, `receipt`, `commission`) |
| Νόμισμα | EUR εξ ορισμού | `Currency` |
| Τρόπος πληρωμής/καταχώρισης | Επιλογή | `PaymentMethod` |
| Αριθμός αναφοράς | Κείμενο | `Reference` |
| Αιτιολογία | Κείμενο | `Description` |
| Ημερομηνία/ώρα · Χρήστης | Αυτόματο | `OccurredAtUtc`, `CreatedByUserId` |

## Απόδοση προς εταιρεία ή πρακτορείο

Βάση: `WorkspaceCardData.Settlements[]`.

| Πεδίο / ενέργεια | Τύπος / κανόνας |
|---|---|
| Ημερομηνία | Ημερομηνία `Date` |
| Ποσό (€) * | Μη μηδενικό `Amount`· θετικό προς φορέα, αρνητικό επιστροφή |
| Αιτιολογία / ασφαλιστήρια | `Note` |
| Τρόπος, αναφορά, νόμισμα | `PaymentMethod`, `Reference`, `Currency` στην αποθηκευμένη εγγραφή |
| Καταχώριση, επεξεργασία, διαγραφή | Μόνο σε αποθηκευμένη καρτέλα· αποθήκευση μετά την πράξη |

## Έσοδα, έξοδα γραφείου και υπερπρομήθειες

Βάση: `OfficeOperation`. Οι γενικές κινήσεις του γραφείου δεν είναι προμήθειες ασφαλιστηρίων.

| Πεδίο | Τύπος / λειτουργία | Ιδιότητα |
|---|---|---|
| Είδος | Έσοδο, έξοδο ή υπερπρομήθεια | `Kind` |
| Ημερομηνία | Ημερομηνία | `OccurredOn` |
| Περιγραφή | Κείμενο | `Description` |
| Κατηγορία | Κείμενο / επιλογή | `Category` |
| Ποσό | Ευρώ | `Amount` |
| Τρόπος πληρωμής | Επιλογή από dropdown | `PaymentMethod` |
| Αναφορά | Κείμενο | `Reference` |
| Σημειώσεις | Κείμενο | `Notes` |
| Συνεργάτης / εταιρεία | Συνδέσεις υπερπρομήθειας | `PartnerId`, `CompanyId` |
| Μικτά / καθαρά ασφάλιστρα | Ποσά | `GrossPremium`, `NetPremium` |
| Προμήθεια έδρας / συνεργάτη / υπερπρομήθεια | Ποσά | `OfficeCommission`, `PartnerCommission`, `OverCommission` |
| Καταχώριση, ενημέρωση, χρήστης | Αυτόματο | `CreatedAtUtc`, `UpdatedAtUtc`, `CreatedByUserId` |

**Πηγή:** `CustomerTransaction.cs`, `PartnerPayout.cs`, `OfficeOperation.cs`, `FinancialMovementCardWindow.cs`, `ReceiptCardWindow.cs`, `OfficeOperationsPage.Editor.cs`.
