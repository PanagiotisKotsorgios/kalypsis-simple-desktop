# Λοιπές καρτέλες και οθόνες

## Γενική καρτέλα ενημέρωσης (`BusinessRecord.SectionKey=updates`)

| Tab | Πεδίο | Τύπος / επιλογές / κλειδί |
|---|---|---|
| Καρτέλα ενημέρωσης | Θέμα * | Κείμενο `title` |
| Καρτέλα ενημέρωσης | Κωδικός | Κείμενο `reference` |
| Καρτέλα ενημέρωσης | Κατάσταση | Πρόχειρο · Ενεργό · Ολοκληρωμένο (`status`) |
| Καρτέλα ενημέρωσης | Κατηγορία | Ανακοίνωση · Υπενθύμιση · Εργασία · Ανανέωση (`category`) |
| Καρτέλα ενημέρωσης | Ημερομηνία | `eventDate` |
| Καρτέλα ενημέρωσης | Περιεχόμενο | Πολυγραμμικό `notes` |
| Καρτέλα ενημέρωσης | Πελάτης | Σύνδεση `customer` |
| Καρτέλα ενημέρωσης | Συνεργάτης | Σύνδεση `partner` |
| Καρτέλα ενημέρωσης | Εταιρεία | Σύνδεση `company` |
| Καρτέλα ενημέρωσης | Ασφαλιστήριο | Σύνδεση `policy` |
| Καρτέλα ενημέρωσης | Ζημιά | Σύνδεση `claim` |
| Σχετικές εγγραφές | Συνδεδεμένες καρτέλες | Προβολή και «Άνοιγμα καρτέλας» για καθεμία |

## Οθόνη «Ενημέρωση» για email/SMS

Η σελίδα αποστολής είναι ξεχωριστή από τη γενική καρτέλα ενημέρωσης παραπάνω.

| Στοιχείο | Επιλογές / λειτουργία |
|---|---|
| Κανάλι | SMS · Email |
| Αναζήτηση | Πελάτης, αριθμός, εταιρεία, κλάδος |
| Είδος εγγράφου | Όλα · Ασφαλιστήρια · Αιτήσεις · Ειδοποιητήρια |
| Εταιρεία, λήξη από/έως | Φίλτρα παραληπτών |
| Πίνακας παραληπτών | Checkbox, Πελάτης, Email, Τηλέφωνο, Αποστολή, Ασφαλιστήριο, Λήξη, Είδος |
| Επιλογή όλων | Μαζική επιλογή checkbox |
| Διπλό κλικ παραλήπτη | Συνοπτική αντιγράψιμη καρτέλα |
| Πρότυπο μηνύματος | Επιλογή, αποθήκευση, διαγραφή |
| Θέμα email | Κείμενο |
| Κυρίως μήνυμα email | Rich text με έντονα, πλάγια, υπογράμμιση, γραμματοσειρά, μέγεθος, χρώμα, στοίχιση, λίστα· κύλιση και μεταβλητό ύψος |
| SMS | Πολυγραμμικό απλό κείμενο |
| Πρόχειρο / προεπισκόπηση / αποστολή | Αντίστοιχες ενέργειες με επιβεβαίωση αποστολής |
| Ρυθμίσεις αποστολής | Brevo email sender/key, Bulker SMS sender/key· ευαίσθητα κλειδιά εκτός αποθετηρίου |
| SMS credits | Προβολή και κουμπί προσθήκης credits |

|---|---|---|

| Καρτέλα αναφοράς | Κωδικός | `reference` |

## Γενική καρτέλα γέφυρας (`SectionKey=bridges`)

| Tab | Πεδίο | Τύπος / επιλογές / κλειδί |
|---|---|---|
| Καρτέλα γέφυρας | Όνομα γέφυρας * | `title` |
| Καρτέλα γέφυρας | Κωδικός | `reference` |
| Καρτέλα γέφυρας | Κατάσταση | Ανενεργό · Ενεργό · Σε δοκιμή (`status`) |
| Καρτέλα γέφυρας | Ασφαλιστική εταιρεία * | Σύνδεση `company` |
| Καρτέλα γέφυρας | Τύπος σύνδεσης | Αρχείο · API · Χειροκίνητη εισαγωγή (`bridgeType`) |
| Καρτέλα γέφυρας | Σημειώσεις | `notes` |
| Καρτέλα γέφυρας | Υπεύθυνος | `contact` |
| Καρτέλα γέφυρας | Email υποστήριξης | `supportEmail` |
| Καρτέλα γέφυρας | Τελευταίος συγχρονισμός | `eventDate` |
| Ρυθμίσεις σύνδεσης | Διεύθυνση υπηρεσίας, Πρωτόκολλο, Μορφή αρχείου, Εξωτερικός κωδικός | `endpoint`, `protocol`, `fileFormat`, `externalCode` |
| Ρυθμίσεις σύνδεσης | Κατεύθυνση | Εισαγωγή · Εξαγωγή · Αμφίδρομη (`direction`) |
| Ρυθμίσεις σύνδεσης | Πρόγραμμα συγχρονισμού, Σημειώσεις αντιστοίχισης | `schedule`, `mapping` |
| Συνδεδεμένη εταιρεία | Σύνδεσμος καρτέλας | Άνοιγμα ασφαλιστικής |

Η **σελίδα «Γέφυρες Εταιρειών»** χρησιμοποιεί επίσης αλφαβητικό κατάλογο εταιρειών/πρακτορείων και εισαγωγή αρχείου. Οι ειδικοί μετατροπείς ανά εταιρεία εξαρτώνται από δείγματα γραμμογράφησης· μην θεωρηθεί ότι κάθε μορφή αρχείου είναι ήδη υποστηριζόμενη.

**Πηγή:** `WorkspaceRecordCardWindow.Fields.cs`, `CommunicationsPage.xaml`, `.xaml.cs`, `CompanyBridgesPage*.cs`.
