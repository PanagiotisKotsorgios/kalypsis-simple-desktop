# Καρτέλα οχήματος

**Αποθήκευση:** `BusinessRecord` με `SectionKey=vehicles`, `CustomerId` και `VehicleCardData` στο `DetailsJson`. Tabs: Καρτέλα οχήματος, Λοιπά, Πρόσωπα, Συμβόλαια, Ζημιές.

## Καρτέλα οχήματος

| Πεδίο | Τύπος / επιλογές | Ιδιότητα |
|---|---|---|
| Πελάτης / ιδιοκτήτης * | Αναζήτηση πελάτη + άνοιγμα καρτέλας | `BusinessRecord.CustomerId`· περιορίζεται η αλλαγή αν υπάρχει ενεργό συμβόλαιο |
| Αριθμός κυκλοφορίας * | Κείμενο | `Registration`· απορρίπτονται αγγλικοί χαρακτήρες με μήνυμα |
| Μάρκα / εργοστάσιο | Κείμενο | `Make` |
| Μοντέλο | Κείμενο | `Model` |
| Αριθμός πλαισίου (VIN) | Κείμενο | `Vin` |
| Έτος κατασκευής | Ακέραιος | `ManufactureYear` |
| Πρώτη άδεια κυκλοφορίας | Ημερομηνία | `FirstRegistrationDate` |
| Θέσεις | Ακέραιος | `Seats` |
| Πόρτες | Ακέραιος | `Doors` |
| Κάμπριο | Ναι/Όχι | `IsConvertible` |

| Χρήση | Παραμετρικός κατάλογος χρήσεων | `Use` |
| Καύσιμο | Κείμενο | `Fuel` |

## Tab «Πρόσωπα»

| Στοιχείο | Τύπος / κανόνας |
|---|---|
| Πρόσωπο | Σύνδεση με `CustomerId`· κλικ στο όνομα ανοίγει πελάτη |
| Ρόλος * | Ιδιοκτήτης · Συνιδιοκτήτης · Οδηγός · Ιδιοκτήτης και οδηγός |
| Ποσοστό ιδιοκτησίας (%) * | `OwnershipPercent`· το άθροισμα ιδιοκτητών δεν υπερβαίνει το 100% |
| Κύριος ιδιοκτήτης | `IsPrimaryOwner`· μία κύρια εγγραφή |
| Προσθήκη / Επεξεργασία / Διαγραφή | Διαχείριση λίστας `People[]` |
| Διπλό κλικ | Ανοίγει επεξεργασία σχέσης προσώπου· κλικ στο σύνδεσμο ανοίγει πελάτη |
