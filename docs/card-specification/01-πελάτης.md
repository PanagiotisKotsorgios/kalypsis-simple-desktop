# Καρτέλα πελάτη

## Κεφαλίδα και πλοήγηση

| Στοιχείο | Συμπεριφορά |
|---|---|
| Ονοματεπώνυμο / επωνυμία | Τίτλος της εγγραφής |
| Ενεργός / ανενεργός | Ένδειξη από `IsActive` |
| Κωδικός πελάτη | `CustomCode` ή αυτόματος `C-` + τμήμα GUID· αντιγραφή και επεξεργασία |
| Tabs | Καρτέλα πελάτη · Λοιπά · Συμβόλαια · Οχήματα · Οικονομικά · Ιστορικό ενεργειών |
| Κατάσταση φόρμας | Προβολή κλειδωμένων πεδίων· «Επεξεργασία πελάτη» ξεκλειδώνει· «Αποθήκευση» αποθηκεύει |

## Tab «Καρτέλα πελάτη»

| Πεδίο | Τύπος / επιλογές | Αποθήκευση / κανόνας |
|---|---|---|
| ΑΦΜ | Αριθμητικό κείμενο, προαιρετικό | `TaxNumber`· αν συμπληρωθεί, **ακριβώς 9 ψηφία** |
| Επώνυμο * | Κείμενο | `LastName` |
| Όνομα * | Κείμενο | `FirstName` |
| Πατρώνυμο | Κείμενο | `FatherName` |
| Φύλο | Κατάλογος «Φύλα» | `Gender` |
| Τόπος γέννησης | Κείμενο | `BirthPlace` |
| Ημ. γέννησης | Ημερομηνία | `BirthDate` |
| Ηλικία | Υπολογισμός | Έτη από `BirthDate`, δεν αποθηκεύεται |
| Κύριο κινητό | Κείμενο | `PrimaryMobile` |
| Κύριο email | Κείμενο | `PrimaryEmail` |
| Διεύθυνση | Κείμενο | `PrimaryAddress` |
| Πόλη | Κατάλογος «Πόλεις», αναζήτηση | `City`· επιλογή από τον κατάλογο |
| Συνεργάτης | Επιλογή καταχωρισμένου συνεργάτη + άνοιγμα καρτέλας | `PartnerName`· απενεργοποιείται όταν «Ανήκει στο γραφείο» |
| Υπόλοιπο πελάτη | Υπολογισμός, χρωματική ένδειξη | `OpeningBalance` + συνδεδεμένες οικονομικές κινήσεις |
| Επικοινωνία | Αναπτυσσόμενος πίνακας | Δείτε πίνακα «Στοιχεία επικοινωνίας» |
| Τύπος ταυτότητας | Κατάλογος «Τύποι ταυτότητας» | `IdentityType` |
| Αριθμός ταυτότητας / άδειας οδήγησης / διαμονής / διαβατηρίου | Κείμενο, δυναμική ετικέτα | `IdentityNumber` ή `LicenseNumber` ανά τύπο |
| Είναι οδηγός | Ναι/Όχι | `IsDriver` |
| Έχει δίπλωμα | Ναι/Όχι | `HasDrivingLicense`· ξεκλειδώνει στοιχεία διπλώματος |
| Νέος οδηγός | Ναι/Όχι | `IsNewDriver` ή αυτόματη ένδειξη από πρόσφατη έναρξη διπλώματος |
| Αρ. διπλώματος | Κείμενο | `LicenseNumber`· κρύβεται αν τύπος ταυτότητας = Άδεια οδήγησης |
| Κατηγορία διπλώματος | Κατάλογος «Κατηγορίες διπλώματος» | `LicenseCategory` |
| Έναρξη διπλώματος | Ημερομηνία | `LicenseStartDate` |
| Λήξη διπλώματος | Ημερομηνία | `LicenseEndDate` |
| Επάγγελμα | Κατάλογος «Επαγγέλματα», αναζήτηση/προσθήκη | `Occupation` |
| Ιθαγένεια | Κατάλογος «Ιθαγένειες» | `Nationality` |
| ΑΜΚΑ | Κείμενο | `SocialSecurityNumber` |
| Τύπος πελάτη | Φυσικό πρόσωπο · Επιχείρηση | `CustomerKind` |
| Ενεργός πελάτης | Ναι/Όχι | `IsActive` |

### Στοιχεία επικοινωνίας

| Στήλη / κουμπί | Λειτουργία |
|---|---|
| Τίτλος | Περιγραφή, π.χ. «2ο κινητό» |
| Περιεχόμενο | Αριθμός, email ή άλλο στοιχείο |
| Προσθήκη | Νέο ζεύγος τίτλου–περιεχομένου |
| Επεξεργασία | Αλλαγή επιλεγμένης εγγραφής |
| Διαγραφή | Αφαίρεση επιλεγμένης εγγραφής |

Ο πίνακας περιλαμβάνει τις ήδη αποθηκευμένες τιμές από τα παρακάτω επιμέρους πεδία, καθώς και ελεύθερα στοιχεία `CustomerDetail` με `Category=contacts`:

| Τίτλος επαφής | Ιδιότητα `Customer` |
|---|---|
| Κύριο κινητό | `PrimaryMobile` |
| Κύριο email | `PrimaryEmail` |
| Σταθερό τηλέφωνο | `HomePhone` |
| 2ο σταθερό τηλέφωνο | `SecondPhone` |
| 3ο σταθερό τηλέφωνο | `ThirdPhone` |
| 2ο κινητό τηλέφωνο | `SecondMobile` |
| 3ο κινητό τηλέφωνο | `ThirdMobile` |
| 2ο email | `SecondEmail` |
| 3ο email | `ThirdEmail` |
| Τηλέφωνο επιχείρησης | `BusinessPhone` |
| Email επιχείρησης | `BusinessEmail` |
| Οποιοσδήποτε νέος τίτλος | `CustomerDetail.Title` + `Value` |

## Tab «Οικονομικά»

| Στοιχείο | Λειτουργία |
|---|---|
| Υπόλοιπο πελάτη | Τρέχον υπολογισμένο υπόλοιπο |
| Παλαιό υπόλοιπο | `OpeningBalance`· αρχικό ποσό πριν από τις κινήσεις |
| Σύνολα εισπράξεων / πληρωμών / μεταφορών | Υπολογισμοί από κινήσεις |
| Αναζήτηση, είδος κίνησης, από/έως | Φίλτρα· είδη: όλες, εισπράξεις, πληρωμές, μεταφορές υπολοίπου |

| Στήλη πίνακα | Περιεχόμενο |
|---|---|
| Ημερομηνία | Χρόνος κίνησης |
| Κίνηση | Είσπραξη, πληρωμή, μεταφορά |
| Ποσό | Ποσό σε ευρώ |
| Αιτιολογία | Περιγραφή / αναφορά |

Διπλό κλικ ανοίγει καρτέλα οικονομικής κίνησης. Οι κινήσεις συνδέονται με πελάτη και, όπου επιλέχθηκε, ασφαλιστήριο.

## Tab «Ιστορικό ενεργειών»

| Στήλη | Περιεχόμενο |
|---|---|
| Ημερομηνία | Χρόνος ενέργειας |
| Ενέργεια | Είδος μεταβολής |
| Περιγραφή | Τι άλλαξε / τι καταχωρίστηκε |

Αναζήτηση, δυναμικό φίλτρο ενέργειας, χρονικό διάστημα, σελιδοποίηση και διπλό κλικ για λεπτομέρειες ενέργειας.

| Κουμπί / πράξη | Ροή |
|---|---|
| Γενική είσπραξη | Νέα είσπραξη για τον πελάτη, σύνδεση ασφαλιστηρίου, τρόπος πληρωμής |
| Γενική πληρωμή | Νέα πληρωμή προς τον πελάτη, σύνδεση ασφαλιστηρίου |
| Μεταφορά υπολοίπου | Μεταφορά πιστωτικού ποσού σε άλλον πελάτη |
| Επεξεργασία πελάτη | Ξεκλείδωμα καρτέλας |
| Αποθήκευση | Έλεγχος υποχρεωτικών και αποθήκευση |
| Κλείσιμο | Κλείνει την καρτέλα |
