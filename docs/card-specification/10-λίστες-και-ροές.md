# Λίστες, φίλτρα και πίνακες

Οι παρακάτω πίνακες περιγράφουν τις **κύριες λίστες** πριν ανοίξει μια καρτέλα. Τα φίλτρα πολλαπλής επιλογής έχουν checkbox, «Επιλογή όλων» και «Αποεπιλογή όλων». Τα φίλτρα ημερομηνίας επιτρέπουν ημερολόγιο και πληκτρολόγηση. Οι στήλες μπορούν να έχουν διαχείριση ορατότητας, αλλαγή πλάτους, μεταφορά και ταξινόμηση ανάλογα με τη λίστα.

| Λίστα | Στήλες με τη σειρά | Φίλτρα |
|---|---|---|
| Πελάτες | Κωδικός, Είδος, Επώνυμο, Όνομα, Επωνυμία, ΑΦΜ, Email, Πόλη, Υπόλοιπο | Ζωντανή αναζήτηση, Υπόλοιπο, Είδος, Πόλη, Συνεργάτης |
| Συνεργάτες | Συνεργάτης, Κωδικός, Πόλη, Τύπος προσώπου, Πιστωτικό όριο, Υπόλοιπο, Κατάσταση | Κατάσταση, Κατηγορία, Πόλη, Τύπος προσώπου |
| Οχήματα | Όχημα, Πινακίδα, Πελάτης, Μάρκα, Χρήση, Πρώτη άδεια, Καύσιμο, Κατάσταση | Κατάσταση, Χρήση, Μάρκα, Πρώτη άδεια από/έως |
| Εταιρείες | Κωδικός, Επωνυμία, ΑΦΜ, Τηλέφωνο, Email, Υπόλοιπο, Κατάσταση | Κατάσταση, Είδος φορέα, Προέλευση |
| Πρακτορεία | Κωδικός, Επωνυμία, ΑΦΜ, Τηλέφωνο, Email, Υπόλοιπο, Κατάσταση | Κατάσταση, Είδος φορέα, Προέλευση |
| Ασφαλιστήρια | Αριθμός συμβολαίου, Πελάτης, Ασφαλιστική, Συνεργάτης, Κλάδος, Έναρξη, Λήξη, Είδος | Κατάσταση, Τύπος εγγράφου, Κλάδος, Εταιρεία, Πρακτορείο, Πελάτης, Συνεργάτης, ημερομηνία έναρξης ή έκδοσης από/έως |
| Ανανεώσεις | Αριθμός συμβολαίου, Πελάτης, Εταιρεία, Κλάδος, Λήξη, Ημέρες για τη λήξη, Ασφάλιστρο | Αναζήτηση, εταιρεία, λήξη από/έως, γρήγορα 30/60 ημέρες |
| Ζημιές | Αριθμός, Συμβόλαιο, Πελάτης, Ασφαλιστική, Ημερομηνία συμβάντος, Κατάσταση | Κατάσταση, Είδος ζημιάς, συμβάν από/έως |
| Ενημέρωση | Checkbox, Πελάτης, Email, Τηλέφωνο, Αποστολή, Ασφαλιστήριο, Λήξη, Είδος | Κανάλι, είδος εγγράφου, εταιρεία, λήξη από/έως |

**Προσοχή:** Η λίστα οχημάτων προβάλλει και παράγωγη κατάσταση ασφάλισης («Ασφαλισμένο», «Σε εξέλιξη», «Χωρίς ενεργό συμβόλαιο»), ενώ στην ίδια την καρτέλα η αποθηκευμένη κατάσταση οχήματος είναι «Ενεργό/Ανενεργό». Το «Είδος» στη λίστα ασφαλιστηρίων είναι ο τύπος εγγράφου, όχι η κατάσταση.

## Κοινές ενέργειες πινάκων

| Ενέργεια | Συμπεριφορά |
|---|---|
| Μονό κλικ στη γραμμή | Επιλογή γραμμής, **χωρίς** αλλαγή του checkbox μαζικής επιλογής |
| Κλικ σε checkbox | Εναλλαγή μαζικής επιλογής συγκεκριμένης γραμμής |
| Checkbox κεφαλίδας | Επιλογή/αποεπιλογή όλων των αποτελεσμάτων |
| Ctrl/Shift, βελάκια | Μαζική επιλογή όπου υλοποιείται στην αντίστοιχη λίστα |
| Διπλό κλικ | Ανοίγει την πλήρη καρτέλα της εγγραφής στο προσκήνιο |
| Δεξί κλικ γραμμής | Άνοιγμα καρτέλας, Επεξεργασία, Διαγραφή |
| Κλικ κεφαλίδας | Ταξινόμηση |
| Δεξί κλικ κεφαλίδας | Αύξουσα/φθίνουσα, μεταφορά αριστερά/δεξιά |
| Σύρσιμο κεφαλίδας | Μεταφορά στήλης |
| Άκρο στήλης | Αλλαγή πλάτους |
| Διαχείριση στηλών | Ορατότητα στηλών της λίστας |
| Προσθήκη / Διαγραφή | Νέα εγγραφή / επιβεβαιωμένη διαγραφή επιλογής |
| Καθαρισμός φίλτρων | Επαναφορά αναζήτησης και φίλτρων |
| Προηγούμενη / Επόμενη | Σελιδοποίηση· κάτω μέρος «Σελίδα Χ από Υ · Σύνολο Ν» |
| Εξαγωγή δεδομένων | Excel `.xlsx` ή CSV `.csv` όπου υπάρχει το κοινό χειριστήριο |
| Εκτύπωση | Προεπισκόπηση, επιλογή στηλών/προσανατολισμού όπου υπάρχει το κοινό χειριστήριο |
| Στενό παράθυρο | Τα φίλτρα μεταφέρονται σε αναδυόμενο κουμπί «Φίλτρα» |

## Ανανεώσεις

| Ενέργεια | Συμπεριφορά |
|---|---|
| 30 ημέρες / 60 ημέρες | Γρήγορη επιλογή χρονικού διαστήματος |
| Ημέρες για τη λήξη | Αριθμός ημερών από σήμερα· χρώμα κινδύνου ανά εγγύτητα λήξης |
| Άνοιγμα / διπλό κλικ | Η υπάρχουσα καρτέλα ασφαλιστηρίου |
| Νέο ανανεωτήριο | Νέα εγγραφή βασισμένη στο επιλεγμένο ασφαλιστήριο, με συνδέσεις προηγούμενου |

## Πίνακες παραγωγής / αναφορές

| Δυνατότητα | Περιγραφή |
|---|---|
| Ομαδοποίηση | Ανά συνεργάτη, εταιρεία ή συνδυασμό, σύμφωνα με τις επιλογές οθόνης |
| Πολλαπλά φίλτρα | Εταιρεία, συνεργάτης, κλάδος, καλύψεις, πακέτο, πελάτης και χρονικό πλαίσιο όπου παρέχονται |
| Αναλυτικές γραμμές | Συμβόλαια με καθαρά, μικτά, προμήθειες και ποσοστά |
| Μερικά σύνολα / γενικό σύνολο | Σύνολο εταιρείας/συνεργάτη και συνολικό αποτέλεσμα |
| Στήλες | Μεταβλητό πλάτος/σειρά/ορατότητα μέσω διαχείρισης |
| Εξαγωγή/εκτύπωση | Επιλογή ορατών στηλών πριν από διαμοιρασμό |
