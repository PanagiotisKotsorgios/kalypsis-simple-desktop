# Καρτέλα εταιρείας

`BusinessRecord.SectionKey=companies`. Βασικά στοιχεία `Title`, `Reference`, `Status`, τα υπόλοιπα στο `WorkspaceCardData.Fields` του `DetailsJson`. Tabs: Καρτέλα εταιρείας, Οικονομικά εταιρείας, Επικοινωνία, Παραγωγή, Ιστορικό ενεργειών.

## Καρτέλα εταιρείας

| Πεδίο | Τύπος / επιλογές | Κλειδί |
|---|---|---|
| Επωνυμία εταιρείας * | Κείμενο | `title` / `BusinessRecord.Title` |
| Κωδικός | Κείμενο, αντιγραφή/επεξεργασία | `reference` / `BusinessRecord.Reference` |
| Κατάσταση | Ενεργό · Ανενεργό · Σε αναστολή | `status` |
| Είδος φορέα | Ασφαλιστική εταιρεία · Μεσίτης · Άλλο | `companyType` |
| Προέλευση | Εσωτερικό · Εξωτερικό | `origin` |
| ΑΦΜ | Κείμενο | `taxNumber` |
| ΔΟΥ | Κείμενο | `taxOffice` |
| Νομική επωνυμία | Κείμενο | `legalName` |
| Τρόπος απόδοσης | Τραπεζική μεταφορά · Συμψηφισμός · Μετρητά | `payoutMethod` |
| Περίοδος απόδοσης | Μηνιαία · Εβδομαδιαία · Ανά ασφαλιστήριο | `payoutPeriod` |
| Πιστωτικό όριο (€) | Αριθμός | `creditLimit` |
| Πιστωτικό όριο ημερών | Αριθμός | `creditDays` |
| Υπόλοιπο | Υπολογισμός | Μικτά ασφαλίστρια − προμήθεια γραφείου επί καθαρών − αποδόσεις |
| Αριθμός συνεργασίας | Κείμενο | `contractNumber` |
| Έναρξη συνεργασίας | Ημερομηνία | `startDate` |
| Λήξη συνεργασίας | Ημερομηνία | `endDate` |
| Υπεύθυνος συνεργασίας | Κείμενο | `manager` |
| Αριθμός άδειας | Κείμενο | `licenseNumber` |
| ΓΕΜΗ | Κείμενο | `gemi` |
| Παρακράτηση φόρου | Ναι/Όχι | `taxWithholding` |
| Κωδικός υποκαταστήματος | Κείμενο | `branchCode` |
| Κωδικός ομαδοποίησης | Κείμενο | `productionCode` |
| Εκτύπωση εντός (ημέρες) | Αριθμός | `printDeadline` |

| Split φόρου | Ναι/Όχι | `splitTax` |

## Οικονομικά εταιρείας

| Στοιχείο | Τύπος / λειτουργία |
|---|---|
| Οικονομική εικόνα / υπόλοιπο | Υπολογίζεται από σχετικά ασφαλιστήρια και `Settlements[]` |
| Ημερομηνία απόδοσης | Ημερομηνία `OrganizationSettlement.Date` |
| Ποσό (€) * | Μη μηδενικό `Amount`· θετικό = απόδοση προς φορέα, αρνητικό = επιστροφή |
| Τρόπος | `PaymentMethod` στην εγγραφή απόδοσης |
| Αναφορά | `Reference` στην εγγραφή απόδοσης |
| Αιτιολογία / ασφαλιστήρια | `Note` |
| Καταχώριση απόδοσης | Διαθέσιμη από την αποθηκευμένη καρτέλα χωρίς λειτουργία επεξεργασίας |
| Επεξεργασία / Διαγραφή | Επιλεγμένη απόδοση, με έλεγχο και επιβεβαίωση |
| Εξαγωγή | Ημερομηνία, ποσό, τρόπος, αναφορά, αιτιολογία |

|---|---|

| Αρχεία επικοινωνίας | Αρχείο, Καταχώριση· προσθήκη PDF/PNG/JPG/JPEG/DOCX, άνοιγμα, διαγραφή, εξαγωγή |

## Παραγωγή και ιστορικό

| Tab | Στήλες / λειτουργία |
|---|---|
| Παραγωγή | Αριθμός συμβολαίου, Κλάδος, Πελάτης, Ασφαλιστική, Έναρξη, Λήξη, Κατάσταση· αναζήτηση, άνοιγμα ασφαλιστηρίου, νέα αίτηση |
| Ιστορικό ενεργειών | Ημερομηνία, ενέργεια, χρήστης/περιγραφή, διπλό κλικ σε λεπτομέρειες |

Κουμπιά καρτέλας: **Καταχώριση απόδοσης**, **Επεξεργασία εταιρείας**, **Αποθήκευση**, **Κλείσιμο**. Οι συνδεδεμένες εγγραφές ανοίγουν μέσω `CompanyId` ή συμβατού ονόματος εταιρείας.

**Πηγή:** `WorkspaceRecordCardWindow.Fields.cs`, `.Organizations.cs`, `.Related.cs`, `WorkspaceCardData.cs`.
