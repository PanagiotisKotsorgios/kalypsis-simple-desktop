# Μοντέλο δεδομένων και κανόνες μεταφοράς

## Κεντρικές οντότητες

| Οντότητα | Κλειδί | Πεδία κορμού | Ειδικά δεδομένα / σχέσεις |
|---|---|---|---|
| `Customer` | `Id: Guid` | `CustomCode`, `LastName`, `FirstName`, `CustomerKind`, `TaxNumber`, επικοινωνία, διεύθυνση, κατάσταση, timestamps | `Details`, `Transactions`, `Activities`, `BusinessRecords` |
| `BusinessRecord` | `Id: Guid` | `SectionKey`, `Title`, `Reference`, `RelatedParty`, `Status`, `DocumentType`, `EventDate`, `Notes`, timestamps | `CustomerId`, `DetailsJson`, συνημμένα |
| `PartnerProfileData` | Μέσα στο `BusinessRecord.DetailsJson` | Ταυτότητα, συνεργασία, επικοινωνία, τράπεζες | `BankAccounts[]` |
| `VehicleCardData` | Μέσα στο `DetailsJson` | Πινακίδα, τεχνικά, ΚΤΕΟ, εξοπλισμός | `People[]`, σύνδεση πελάτη/ασφαλιστηρίων |
| `PolicyCardData` | Μέσα στο `DetailsJson` | Τύπος, αριθμοί, ημερομηνίες, ασφάλιστρα, εταιρεία, πακέτο, προμήθειες | `Coverages[]`, `Installments[]`, `InsuredObjects[]`, `Endorsements[]`, `GreenCards[]` |
| `WorkspaceCardData` | Μέσα στο `DetailsJson` | Λεξικό `Fields` ανά εταιρεία/πρακτορείο/ζημιά/ενημέρωση/αναφορά/γέφυρα | IDs συνδεδεμένων εγγραφών, `Contacts[]`, `Settlements[]` |
| `CustomerTransaction` | `Id: Guid` | `Type`, `Amount`, `PaymentMethod`, `Currency`, `Reference`, `Description`, `OccurredAtUtc` | `CustomerId`, προαιρετικό `BusinessRecordId` ασφαλιστηρίου |
| `PartnerPayout` | `Id: Guid` | `Kind`, `Amount`, `PaymentMethod`, `Currency`, `Reference`, `Description`, `OccurredAtUtc` | `PartnerId`, προαιρετικό `PolicyId` |
| `OfficeOperation` | `Id: Guid` | `Kind`, `OccurredOn`, `Description`, `Category`, `Amount`, `PaymentMethod`, `Reference`, `Notes` | `PartnerId`, `CompanyId`, ασφάλιστρα/προμήθειες |

## Σχέσεις που πρέπει να διατηρηθούν

| Από | Προς | Πεδίο / κανόνας |
|---|---|---|
| Πελάτης | Συνεργάτης | `PartnerName` και καταχωρισμένη εγγραφή συνεργάτη· χρειάζεται αντιστοίχιση στο νέο σύστημα |
| Πελάτης | Πελάτης/συνεργάτης σύστασης | `ReferredByCustomerId` / `ReferredByPartnerName` |
| Όχημα | Πελάτης | `BusinessRecord.CustomerId`; επιπλέον πολλοί `VehiclePerson.CustomerId` |
| Ασφαλιστήριο | Πελάτης | `BusinessRecord.CustomerId`; προαιρετικός άλλος συμβαλλόμενος `HolderCustomerId` |
| Ασφαλιστήριο | Όχημα | `PolicyCardData.VehicleId`· μόνο συνδεδεμένα οχήματα πελάτη στη φόρμα |
| Ασφαλιστήριο | Εταιρεία / πρακτορείο | `CompanyId`, `AgencyId` μαζί με ονόματα `Insurer`, `Agency` |
| Ασφαλιστήριο | Συνεργάτης | `PartnerId` |
| Ανανέωση | Προηγούμενο ασφαλιστήριο | `PreviousPolicyId`, `PreviousPolicyNumber`, `RenewalNumber` |
| Είσπραξη/πληρωμή | Πελάτης + ασφαλιστήριο | `CustomerId`, `BusinessRecordId` |
| Προμήθεια/πληρωμή συνεργάτη | Συνεργάτης + ασφαλιστήριο | `PartnerId`, `PolicyId` |
| Ζημιά | Πελάτης, ασφαλιστήριο, όχημα, εταιρεία | IDs συνδέσεων `WorkspaceCardData` και `ClaimCardData.VehicleId` |
| Εταιρεία/πρακτορείο | Ασφαλιστήρια | `CompanyId`/`AgencyId`, με παλιές εγγραφές να μπορούν να αντιστοιχιστούν και από όνομα |

## Υπολογισμοί και έλεγχοι

| Κανόνας | Περιγραφή |
|---|---|
| ΑΦΜ πελάτη | Προαιρετικό, αν δοθεί ακριβώς 9 αριθμητικά ψηφία |
| ΑΦΜ συνεργάτη | Υποχρεωτικό, 9 ψηφία |
| Πινακίδα | Υποχρεωτική, αγγλικοί ASCII χαρακτήρες απορρίπτονται |
| Δίπλωμα πελάτη | Στοιχεία διπλώματος ξεκλειδώνουν μόνο αν «Έχει δίπλωμα» |
| Ιδιοκτησία οχήματος | Ποσοστά ιδιοκτητών αθροιστικά έως 100%, κύριος ιδιοκτήτης |
| Υπόλοιπο ασφαλιστηρίου | Μικτά − εισπράξεις + πληρωμές/επιστροφές προς πελάτη |
| Προμήθειες | Ποσοστά έδρας και συνεργάτη **επί καθαρών ασφαλίστρων**· κανόνας ανά εταιρεία, κλάδο, χρήση, καλύψεις, πακέτο |
| Οφειλή προς εταιρεία | Μικτά − προμήθεια γραφείου επί καθαρών − καταχωρισμένες αποδόσεις |
| Προθεσμία απόδοσης | Ημερομηνία έκδοσης + πιστωτικές ημέρες εταιρείας, εφόσον δεν έχει δοθεί ρητή ημερομηνία |
| Ηλικία, διάρκεια, μέρες λήξης | Παράγωγα στοιχεία, υπολογίζονται αντί να αντιγράφονται ως στατικές τιμές |
| Ιστορικό | Διατήρηση δημιουργού/χρόνου και αυτόματων εγγραφών ενεργειών |
