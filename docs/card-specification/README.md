## Πώς διαβάζονται οι πίνακες

| Σήμανση | Σημασία |
|---|---|
| `Κείμενο`, `Ποσό`, `Ημερομηνία`, `Ναι/Όχι` | Τύπος στοιχείου ελέγχου / δεδομένων |
| `Κατάλογος` | Επιλογή από παραμετρικά δεδομένα συστήματος, συχνά με ζωντανή αναζήτηση |
| `Σύνδεση` | Επιλογή υπαρκτής εγγραφής με αναγνωριστικό και άνοιγμα της σχετικής καρτέλας |
| `Υπολογισμός` | Προβολή που προκύπτει από άλλα δεδομένα, χωρίς άμεση πληκτρολόγηση |
| `JSON key` | Κλειδί μέσα στο `DetailsJson` της κοινής εγγραφής, όπου χρησιμοποιείται |

Η τεκμηρίωση περιγράφει την **υλοποιημένη επιφάνεια και το μοντέλο**. Για πιστή μεταφορά απαιτείται επιπλέον μεταφορά των υπηρεσιών, ελέγχων πρόσβασης, migrations, υπολογισμών και μορφοποίησης από τον πηγαίο κώδικα· οι πίνακες δεν αποτελούν από μόνοι τους εκτελέσιμη προδιαγραφή κάθε εσωτερικής ροής.
