# Καρτέλα ζημιάς

`BusinessRecord.SectionKey=claims`, ειδικά πεδία στο `WorkspaceCardData.Fields` και σύνδεση οχήματος στο `ClaimCardData`. Tabs: Καρτέλα ζημιάς, Πρόσθετα στοιχεία, Όχημα & συμβόλαιο, Οικονομικά, Εμπλεκόμενοι, Ιστορικό ενεργειών.

## Καρτέλα ζημιάς

| Πεδίο | Τύπος / επιλογές | Κλειδί |
|---|---|---|
| Αριθμός ζημιάς * | Κείμενο | `title` |
| Αρ. φακέλου ασφαλιστικής | Κείμενο | `reference` |
| Κατάσταση | Δηλωμένη · Σε αναμονή · Σε εξέλιξη · Εγκρίθηκε · Πληρωμένη · Κλειστή · Απορρίφθηκε | `status` |
| Είδος ζημιάς | Ζημιά οχήματος · Ζημιά τρίτου · Κλοπή · Πλημμύρα · Υγεία · Κατοικία · Σκάφος · Αστική ευθύνη · Άλλο | `claimType` |
| Ημερομηνία συμβάντος | Ημερομηνία | `eventDate` |
| Ώρα συμβάντος | Κείμενο ώρας | `eventTime` |
| Τόπος / διεύθυνση | Κείμενο | `incidentLocation` |
| Πόλη συμβάντος | Κείμενο | `incidentCity` |
| Ημερομηνία δήλωσης | Ημερομηνία | `reportedDate` |
| Περιγραφή | Πολυγραμμικό | `notes` |
| Πελάτης / ασφαλισμένος * | Σύνδεση πελάτη | `customer` / `CustomerId` |
| Ασφαλιστήριο | Σύνδεση | `policy` |
| Όχημα | Σύνδεση | `vehicle` |
| Ασφαλιστική εταιρεία | Σύνδεση | `company` |
| Πρακτορείο | Σύνδεση | `agency` |
| Συνεργάτης | Σύνδεση | `partner` |
