# Καρτέλα πρακτορείου

`BusinessRecord.SectionKey=agencies`. Κοινή υποδομή με την εταιρεία, ειδικά πεδία στο `WorkspaceCardData.Fields`. Tabs: Καρτέλα πρακτορείου, Οικονομικά πρακτορείου, Επικοινωνία, Ασφαλιστήρια, Ιστορικό ενεργειών.

## Καρτέλα πρακτορείου

| Πεδίο | Τύπος / επιλογές | Κλειδί |
|---|---|---|
| Επωνυμία πρακτορείου * | Κείμενο | `title` |
| Κωδικός | Κείμενο | `reference` |
| Κατάσταση | Ενεργό · Ανενεργό · Σε αναστολή | `status` |
| Είδος φορέα | Πρακτορείο · Υποκατάστημα · Συνεργαζόμενο δίκτυο | `agencyType` |
| Προέλευση | Εσωτερικό · Εξωτερικό | `origin` |
| Ασφαλιστική εταιρεία | Σύνδεση σε καταχωρισμένη εταιρεία | `company` + αναγνωριστικό σύνδεσης |
| Περιοχή | Κείμενο | `area` |
| Υπεύθυνος | Κείμενο | `manager` |
| ΑΦΜ | Κείμενο | `taxNumber` |
| Τρόπος απόδοσης | Τραπεζική μεταφορά · Συμψηφισμός · Μετρητά | `payoutMethod` |
| Πιστωτικό όριο (€) | Αριθμός | `creditLimit` |
| Πιστωτικό όριο ημερών | Αριθμός | `creditDays` |
| Υπόλοιπο | Υπολογισμός από ασφαλιστήρια και αποδόσεις | `balance` προβολής |
| Αριθμός σύμβασης | Κείμενο | `contractNumber` |
| Έναρξη συνεργασίας | Ημερομηνία | `startDate` |
| Λήξη συνεργασίας | Ημερομηνία | `endDate` |
| Κωδικός υποκαταστήματος | Κείμενο | `branchCode` |
| Σημειώσεις | Πολυγραμμικό | `notes` |

## Οικονομικά πρακτορείου

| Στήλη / πεδίο | Περιεχόμενο |
|---|---|
| Ημερομηνία | `OrganizationSettlement.Date` |
| Ποσό (€) * | `Amount`, μη μηδενικό· θετικό απόδοση, αρνητικό επιστροφή |
| Τρόπος | `PaymentMethod` |
| Αναφορά | `Reference` |
| Αιτιολογία / ασφαλιστήρια | `Note` |
| Υπόλοιπο | Μικτά − προμήθεια γραφείου επί καθαρών − αποδόσεις |
| Κουμπιά | Καταχώριση απόδοσης, επεξεργασία, διαγραφή, εξαγωγή |

## Επικοινωνία

| Πεδίο | Κλειδί |
|---|---|
| Τηλέφωνο | `phone` |
| Κινητό | `mobile` |
| Email | `email` |
| Ιστότοπος | `website` |
| Διεύθυνση | `address` |
| Πόλη | `city` |
| Τ.Κ. | `postalCode` |
| Πρόσωπο επικοινωνίας | `contact` |

| Υποπίνακας | Στήλες / ενέργειες |
|---|---|
| Πρόσωπα επικοινωνίας | Όνομα*, Ιδιότητα/τμήμα, Email, Κινητό, Τηλέφωνο· αναζήτηση, προσθήκη, επεξεργασία, διαγραφή, διπλό κλικ σε καρτέλα, εξαγωγή |
| Αρχεία επικοινωνίας | Αρχείο, Καταχώριση· επισύναψη, άνοιγμα, διαγραφή, εξαγωγή |

## Ασφαλιστήρια / ιστορικό / κουμπιά

| Στοιχείο | Λειτουργία |
|---|---|
| Πίνακας ασφαλιστηρίων | Αριθμός συμβολαίου, Κλάδος, Πελάτης, Ασφαλιστική, Έναρξη, Λήξη, Κατάσταση |
| Νέα αίτηση ασφάλισης | Προσυμπληρώνει το πρακτορείο |
| Διπλό κλικ ασφαλιστηρίου | Ανοίγει την καρτέλα ασφάλισης |
| Ιστορικό ενεργειών | Αυτόματες μεταβολές, διπλό κλικ σε λεπτομέρειες |
| Καταχώριση απόδοσης / Επεξεργασία / Αποθήκευση / Κλείσιμο | Βασικές ενέργειες καρτέλας |
