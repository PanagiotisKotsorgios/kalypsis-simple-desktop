# Καρτέλα συνεργάτη

**Αποθήκευση:** `BusinessRecord` με `SectionKey=partners`; τα ειδικά πεδία στο `PartnerProfileData` του `DetailsJson`. Η κεφαλίδα δείχνει όνομα, κατάσταση, κωδικό (αντιγραφή/επεξεργασία). Tabs: Καρτέλα συνεργάτη, Ασφαλιστήρια, Πελάτες, Οικονομικά, Ιστορικό ενεργειών.

## Καρτέλα συνεργάτη

| Πεδίο | Τύπος / επιλογές | Ιδιότητα |
|---|---|---|
| Επώνυμο * | Κείμενο· υποχρεωτικό για φυσικό πρόσωπο | `LastName` |
| Όνομα * | Κείμενο· υποχρεωτικό για φυσικό πρόσωπο | `FirstName` |
| Επωνυμία επιχείρησης | Κείμενο· υποχρεωτική για νομικό πρόσωπο | `CompanyName` |
| ΑΦΜ * | Ακριβώς 9 ψηφία | `TaxNumber` |
| ΔΟΥ | Παραμετρικός κατάλογος, αναζήτηση | `TaxOffice` |
| Τύπος προσώπου * | Φυσικό πρόσωπο · Νομικό πρόσωπο | `PersonType` |
| Τύπος επιχείρησης | Παραμετρικός κατάλογος | `BusinessType` |
| Επαγγελματική ιδιότητα | Παραμετρικός κατάλογος | `ProfessionalCapacity` |
| Αριθμός ταυτότητας | Κείμενο | `IdentityNumber` |
| Αριθμός ΓΕΜΗ | Κείμενο | `GemiNumber` |
| Υπεύθυνος συνεργασίας | Κείμενο | `CooperationManager` |
| Κατάσταση * | Ενεργός · Πιθανός · Αναστολή · Λήξη συνεργασίας | `BusinessRecord.Status` |
| Κατηγορία συνεργάτη | Παραμετρικός κατάλογος | `Category` |
| Ενεργή σύμβαση | Ναι/Όχι | `HasActiveContract` |
| 1ο email | Κείμενο | `Email` |
| Σταθερό τηλέφωνο | Κείμενο | `Phone` |
| Κύρια διεύθυνση | Κείμενο | `Address` |
| Πόλη | Παραμετρικός κατάλογος, αναζήτηση | `City` |
| Ταχυδρομικός κώδικας | Κείμενο | `PostalCode` |
| Αριθμός σύμβασης | Κείμενο | `ContractNumber` |
| Έναρξη συνεργασίας | Ημερομηνία | `StartDate` |
| Λήξη συνεργασίας | Ημερομηνία | `EndDate` |
| Πιστωτικό όριο (€) | Ποσό | `CreditLimit` |
| Προτιμώμενος τρόπος πληρωμής | Παραμετρικός κατάλογος | `PaymentMethod` |
| Υπόλοιπο συνεργάτη | Υπολογισμός από προμήθειες και κινήσεις | Δεν πληκτρολογείται |

### Τράπεζες / IBAN

| Στήλη / ενέργεια | Τύπος / λειτουργία |
|---|---|
| Τράπεζα * | Κείμενο `BankName` |
| IBAN * | Κείμενο `Iban` |
| BIC / SWIFT | Κείμενο `Bic` |
| Προσθήκη, επεξεργασία, διαγραφή | Διαχείριση `BankAccounts[]` μέσα στην καρτέλα |

Το άνοιγμα του αναπτυσσόμενου τμήματος μετακινεί αυτόματα την κύλιση ώστε να φανεί το περιεχόμενο.

## Συνδεδεμένοι πίνακες

| Tab | Στήλες, με τη σειρά | Φίλτρα / άνοιγμα |
|---|---|---|
| Ασφαλιστήρια | Αριθμός συμβολαίου · Πελάτης · Έναρξη · Καθαρά · Μεικτά · Προμήθεια συνεργάτη | Ζωντανή αναζήτηση· διπλό κλικ ανοίγει ασφαλιστήριο |
| Πελάτες | Πελάτης · ΑΦΜ · Πόλη · Κατάσταση · Υπόλοιπο | Ζωντανή αναζήτηση· διπλό κλικ ανοίγει πελάτη |
| Οικονομικά | Ημερομηνία · Κίνηση · Αναφορά · Περιγραφή · Προμήθεια · Πληρώθηκαν · Εισπράχθηκαν · Υπόλοιπο | Αναζήτηση, κίνηση, μήνας/από/έως, διπλό κλικ σε κίνηση |
| Ιστορικό ενεργειών | Ημερομηνία · Ενέργεια · Περιγραφή · Χρήστης | Αναζήτηση/διπλό κλικ σε λεπτομέρειες |

## Ενέργειες

| Κουμπί | Λειτουργία |
|---|---|
| Γενική είσπραξη | Είσπραξη από συνεργάτη, ποσό, τρόπος, αναφορά, αιτιολογία |
| Γενική πληρωμή | Πληρωμή προς συνεργάτη, ποσό, τρόπος, αναφορά, αιτιολογία |

| Προσθήκη / επεξεργασία / διαγραφή τράπεζας | Διαχείριση πολλών τραπεζικών λογαριασμών |
