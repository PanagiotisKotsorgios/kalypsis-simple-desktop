# Γέφυρες Υδρόγειος και Ορίζων

Οι δύο μετατροπείς αφορούν τη γραμμογράφηση των δειγμάτων `PARG101290` και
`carhist_on_..._for_Vehicle_...`. Το αρχείο της Υδρογείου είναι CP737 με κόμμα.
Το αρχείο της Ορίζων είναι UTF-8 με ελληνικό περιεχόμενο και διαχωριστικό `;`.
Δεν υπάρχει γραμμή επικεφαλίδων. Οι θέσεις παρακάτω είναι μηδενικής βάσης.

| Θέση | Στοιχείο |
| --- | --- |
| 0 | Αριθμός ασφαλιστηρίου |
| 1 | Αριθμός προηγούμενου, όταν δεν είναι μηδενικός |
| 5, 6, 7 | Έκδοση, έναρξη, λήξη σε `ηηΜΜεεεε` |
| 8 | Ένδειξη ακύρωσης `99` |
| 10 | Κωδικός συνεργάτη για αντιστοίχιση |
| 12, 19 | Όνομα και ΑΦΜ πελάτη |
| 16, 28 | Κωδικοί κλάδου και χρήσης |
| 27, 34 | Πινακίδα και μάρκα οχήματος |
| 52, 59 | Καθαρά και μικτά ασφάλιστρα σε λεπτά του ευρώ |
| 61+ / 62+ | Τετράδες καλύψεων Υδρογείου / Ορίζων: κωδικός, κεφάλαιο, απαλλαγή, ασφάλιστρο |

Οι άγνωστοι κωδικοί κλάδων, χρήσεων, καλύψεων και συνεργατών αντιστοιχίζονται
πριν την εισαγωγή. Οι επιλογές αποθηκεύονται στη βάση ως εσωτερικές τιμές
`bridge:`. Νέοι πελάτες και οχήματα δημιουργούνται μόνο με ρητή επιλογή στην
προεπισκόπηση. Οι ακυρώσεις ενημερώνουν το υπάρχον ασφαλιστήριο του ίδιου
πελάτη και εταιρείας. Οι ίδιες εγγραφές δεν εισάγονται ξανά.

Οι δοκιμές διαβάζουν τα πραγματικά αρχεία μόνο όταν υπάρχουν στον φάκελο
`Downloads` του μηχανήματος εκτέλεσης. Για έλεγχο εγγραφής χρησιμοποιούν
απομονωμένη προσωρινή SQLite βάση, η οποία διαγράφεται μετά τη δοκιμή.
